# YouTube content planner

Date: 2026-10-11 (Australia/Sydney)
Task identifier: not available (Claude Code session)

## Request and evidence

User wants short (10 minutes max) YouTube videos about IT and AI across Databricks, Snowflake, BigQuery, Fabric, Claude, OpenAI, Gemini, dbt and Power BI, asked for the 50 best concepts that guarantee views, then asked for a dedicated, clearly separate folder in this repo, inviting questions.

## Changes and decisions

Told the user views cannot be guaranteed and that search demand and competition were not checked. Created [youtube-content/](../youtube-content/README.md): README, [VIDEO_PLANNER.md](../youtube-content/VIDEO_PLANNER.md) (50 ideas by platform with hook, priority, readiness and supporting guide links), [video-planner.csv](../youtube-content/video-planner.csv) for tracking status/demand checks/publish dates, and [PRODUCTION_CHECKLIST.md](../youtube-content/PRODUCTION_CHECKLIST.md) (demand check, 10-minute structure, title/thumbnail rules, pre-publish safety check). Counts: 17 High, 29 Medium, 4 Low; 10 Ready, 12 Partly, 28 Needs research. Both files and the CSV were generated by one script so they match, and relative links were checked. Priorities are judgement calls based on search intent and existing material. Decided not to block on questions: listed three optional ones in the folder README (channel name/audience, French versions, recording on a personal workspace because this is a work laptop).

## Validation and unresolved issues

Link existence checked locally. No YouTube data, search volume or analytics were consulted. Next step: user runs the demand check on the High/Ready ideas, answers the open questions and picks the first video.
