## Brand and architecture

Wonder Hollow makes gentle educational videos and browser games for preschool children
aged 3–5. Four Australian animal friends: Mossy the koala, Tilly the quokka,
Rufus the kookaburra, and Bimble the bilby. Internal identifiers remain
`koala`, `quokka`, `kookaburra`, `bimble`; display names are separate.

The website is static HTML served from `website/`, with six browser games. The catalogue
contained 26 episode links at this audit. Future books and merchandise are previews;
nothing was for sale. Do not introduce unsupported product availability claims.

The existing production architecture uses GitHub Actions, Claude script generation,
Replicate backgrounds, ElevenLabs narration, FFmpeg assembly and YouTube uploads.
Characters use locked artwork; the cast is not regenerated by an image model for each
scene. This production context comes from the source and earlier project memory, rather
than a new end-to-end episode production test in this session.

## Critical continuity rules

1. The ledger records uploads, including private uploads. A `youtube_id` does not prove
   human approval or public availability. Ledger date is not a verified public release date.
2. Uploads remain private and Made for Kids. A person must watch the finished video before
   publication. Website optimisation does not authorise bypassing that gate.
3. `scripts/build_website.py` owns markup between the EPISODES markers. Update the
   generator when changing the catalogue or the next build overwrites hand edits.
4. Website deployment now has its own workflow. Do not generate a paid episode merely
   to deploy a site change.
5. The confirmed state is as of this session. Recheck current source, workflows, live
   pages and connections before subsequent changes. Never store credentials here.
