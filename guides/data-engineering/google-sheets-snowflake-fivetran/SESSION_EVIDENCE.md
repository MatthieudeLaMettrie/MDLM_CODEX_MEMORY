## 2 October follow-up: FEI database

The user reported that changing only the Fivetran database field from FIVETRAN_DATABASE to FEI failed, then requested that the permissions explanation and grant SQL be added to this repository. The original setup grants were scoped to FIVETRAN_DATABASE, making missing FEI grants the likely explanation. Added the administrator-run USAGE/MONITOR/CREATE SCHEMA grant on FEI to FIVETRAN_ROLE and the Save & Test instructions. No exact error, live grants, or successful retry was observed.
