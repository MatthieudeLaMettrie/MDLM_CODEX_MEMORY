01 / The foundation

What is a runtime?

A runtime environment is the software that executes your program and supplies the services it needs while running.

A .js or .py file is stored text containing instructions. A compatible runtime reads those instructions, executes them, manages things such as memory and errors, and provides access to supported features such as files or networking.

Language

The rules you write in

JavaScript and Python define syntax and behaviour. A language is a specification; it needs an implementation to execute programs.

Engine / interpreter

The execution machinery

V8 executes JavaScript. CPython is the standard Python implementation. Execution can involve interpretation, bytecode or compilation.

Runtime environment

The working environment

Combines execution machinery with supporting services and APIs. Node.js includes V8 plus facilities such as file access and networking.

Two meanings of “runtime”: “Install a runtime” refers to the software environment. “An error at runtime” means an error that occurs while the program is executing. An interpreter can form the core of a runtime; these terms overlap in everyday Python discussions.

An editor is another part of the picture

VS Code and PyCharm help you write and launch code. A terminal displays a command interface; a shell such as PowerShell processes commands. When you type node hello.js, the shell launches Node.js, and Node executes the JavaScript.

Think of a recipe: the language is its notation, the source file is the written recipe, the engine is the cook, and the runtime is the working kitchen with its available equipment. The analogy explains roles, not exact software internals. Read: JavaScript engines and host environments.

02 / Three tools, different jobs

Node.js, npm and npx

Execute your program

Node.js

A JavaScript runtime outside the browser. Useful for servers, APIs, automation and development tools.

node app.js

“Run this JavaScript file.”

Manage packages

npm

Installs and manages reusable code and tools. Also runs named project scripts and publishes packages.

npm install express

“Add Express to this project.”

Invoke a package command

npx

Runs a command provided by a package. Can use a local dependency or fetch a missing package into npm’s cache.

npx prettier --check .

“Run Prettier to check this folder.”

The official Node installer typically includes npm and npx. Other installation methods may package them separately. Sources: Node.js, npm, npx.

03 / The execution map

Where can .js and .py files run?

Separate the place code runs from the runtime executing it.

A laptop, server, virtual machine or container can host a runtime. “In the cloud” tells you where execution happens; it does not identify the runtime.

04 / Connect the commands to the concepts

Two files. Two runtimes.

Save these files in a practice folder. Open a terminal in that folder. Each runtime must be installed and available on your command path.

JavaScript · hello.js
console.log("Hello from JavaScript!");

Choose one installed JavaScript runtime:

node hello.js
deno run hello.js
bun run hello.js

Each prints Hello from JavaScript! for this simple example.

Python · hello.py
print("Hello from Python!")

Choose the command matching your installation:

python hello.py
python3 hello.py
py hello.py

Each launches a configured Python interpreter to print Hello from Python!. The py command is a Windows launcher/manager entry point, not a distinct Python implementation.

Run the JavaScript file in a browser

Save the following as index.html beside hello.js, open the HTML file in your browser, then open its developer console to see the output. This simple classic script example needs no server.

<!doctype html>
<html lang="en">
  <head><meta charset="utf-8"><title>Practice</title></head>
  <body>
    <h1>Open the developer console</h1>
    <script src="hello.js"></script>
  </body>
</html>

JavaScript modules and network requests often need a local web server rather than a file:// page. Do not assume this simple example covers every browser app.

Use a Python virtual environment for project dependencies. python -m pip runs pip with that selected interpreter. Unlike npx, python -m does not download a missing module; the module must already be available and support execution.

Common “why did that fail?” moments

“node” or “python” is not recognized

The shell cannot find the command. Check installation, the command name and PATH. Restart the terminal after an installer changes PATH. On your system, the Python command might be python3 or py.

“Cannot find module” or “ModuleNotFoundError”

A dependency may be missing, or you may be using the wrong project folder, interpreter or virtual environment. Installing into one Python environment does not make a package available in every environment.

“document is not defined” in Node.js

The code expects browser page APIs. Run it in a browser or adapt the code for the intended environment. Sharing a JavaScript engine does not make Node and the browser identical.

Can Node.js run Python, or Python run JavaScript?

Neither normally executes the other language directly. A program can launch another runtime as a separate process or embed an implementation. If Node launches Python, Python still executes the .py code.

Explain it back in one minute

A runtime executes my code and supplies its working environment. Node.js runs JavaScript outside browsers; npm manages packages and scripts; npx invokes package commands without requiring global installation. Python is commonly executed by CPython, with other implementations for different needs. An editor, terminal, container or cloud service still relies on a runtime to execute the language.
